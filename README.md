
# Basketball Scoreboard

## About the Project
A simple basketball scoreboard built using HTML, CSS,
and JavaScript as part of my full-stack development
learning journey.

## Features
- Separate scores for Home and Guest teams
- Add 1, 2, or 3 points
- Dynamic score updates
- Simple user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone this repository.
2. Open index.html in your browser.
